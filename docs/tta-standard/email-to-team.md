**참조**: (필요 시)

**제목**: [표준화] AI 에이전트 권한위임 — TTA 표준 아이템 제안 자료 (특허 매핑 + 초안 v0.2)

---

정종식 박사님, 김정소 이사님

지난 유순덕 교수님(한세대) 미팅 후속으로, 우리 등록특허를 TTA 표준 아이템으로 추진하기 위한 1차 자료를 정리해 공유드립니다. 6월 말~7월 초 본격 착수를 목표로, 내부 검토 후 교수님께 전달할 패키지입니다.

## 1. 핵심 요지

- **자산**: 등록특허 **10-2025-0074709**(사용자→AI에이전트 권한위임). 출원 2025-06-09, **등록결정 2026-02-05** 완료. 구현체(meta-agents v0.3.0)가 Metadium testnet에 이미 배포되어 있어 표준의 reference implementation으로 인용 가능합니다.
- **차별성/타이밍**: 우리 출원이 OIDF whitepaper(2025-10)·DIF MCP-I(2026-03)·관련 논문(2026-01)보다 앞섭니다. 글로벌 표준(OIDF/DIF/W3C)은 블록체인을 *옵션*으로만 두는 반면, 우리는 **온체인 등록·검증을 필수로 결합**한 유일한 등록 IP입니다. → first-mover 명분이 충분합니다.
- **포지셔닝**: 유 교수님의 상위 거버넌스 프레임("Agent Trustworthiness Governance Framework")과 **종속이 아닌 상호참조(family) 구도**로 묶는 것을 제안합니다. 우리는 *하위 프로토콜 표준*(어떻게 위임·검증·감사할지)을 담당합니다.

## 2. 첨부 자료

1. **`patent-to-standard-mapping.md`** — 등록특허 청구항 1~24를 표준 조항으로 매핑한 표 + IPR 확약 전략 + 글로벌 우선순위 비교
2. **`draft-v0.2.md`** — TTA 양식 표준 초안. 1~7장 구성, **5장(구조)·6장(시나리오) 본문 작성 완료**. 5·6장은 v0.3 구현 스펙을 역문서화한 것이라 신규 R&D가 필요 없습니다.

## 3. 제안 표준 아이템

- **제목(안)**: 「블록체인 기반 AI 에이전트 권한위임 및 검증 프로토콜」
- **소관 PG 후보**: PG1006(블록체인기반기술) 1순위 / PG502(블록체인 보안) 대안
- **IPR**: 표준 부록에 등록특허를 declare하여 권리 보존 + 표준 채택을 양립

## 4. 요청 / 다음 단계

- **정종식 박사님**: 첨부 매핑표·초안 검토 후, 표준 아이템 범위(독자 제안 vs 거버넌스 프레임 연계) 의견 부탁드립니다. 교수님 전달용 특허 정리본도 함께 준비 부탁드립니다.
- **김정소 이사님**: 교수님 일정(파리 출장 중 줌/메일 가능)에 맞춰 다음 미팅 조율 부탁드립니다.
- 확인 필요 사항: 교수님 TC307 의장 출마 건, "TS23354 감리 가이드라인" 표준번호 — 줌 미팅에서 직접 확인 요망(현재 미검증).

검토 의견 주시면 반영해 v0.3로 업데이트하겠습니다.
