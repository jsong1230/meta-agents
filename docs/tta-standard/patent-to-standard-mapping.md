## 4. 지식재산권 확약(IPR) 메모

- 표준안 부록 I-1 「지식재산권 확약서 정보」에 **등록특허 10-2957866**을 명시 declare 한다.
- TTA IPR 정책(RAND 등) 검토 후, 표준 채택과 IP 권리 보존을 양립시킨다.
- 효과: 본 프레임워크가 표준으로 채택되어도 출원인의 권리가 보존되며, 경쟁사가 표준 준수 시 본 IP를 인지·우회·라이선스해야 하는 first-mover 구조가 성립한다.

## 5. 표준화 트랙 포지셔닝

```
[상위] Agent Trustworthiness Governance Framework  (유순덕 교수 / 거버넌스·서비스형)
          │  2단계 Transaction Level: 스마트컨트랙트 규칙 준수, 변경 추적
          │  └── 참조(family) ─────────────────┐
          ▼                                     │
[하위] 에이전트 권한위임 및 검증을 위한 블록체인 기반 신뢰 프레임워크  (본 아이템 / 프레임워크·개발형)
          └── 등록특허 10-2957866 + meta-agents v0.3.0 구현체
```

- **종속이 아닌 상호참조(family) 구도**를 목표로 한다. 거버넌스 프레임은 *무엇을 신뢰성 있게 관리할지*, 본 프레임워크는 *어떻게 위임·검증·감사할지*를 규정한다.
- 소관 PG 후보: **PG1006(블록체인기반기술)** 1순위, **PG502(블록체인 보안)** 대안. 보안 요구사항(7장)을 강화하면 PG502 적합성↑.
