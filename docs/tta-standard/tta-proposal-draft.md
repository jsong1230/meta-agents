## 2. 표준화 필요성

### 가. 배경

자율적 AI 에이전트가 사용자를 대리하여 결제·거래·계약 등 실질적 권한 행사를 수행하는 서비스가 급속히 확산되고 있다. 그러나 현재의 에이전트 위임은 API 키·세션 토큰 등 서비스별 임시방편에 의존하여 다음 문제를 야기한다.

1. **권한 초과 행위**: 에이전트가 위임 범위를 벗어난 행위를 수행해도 이를 기술적으로 차단·검증할 표준 절차가 없음
2. **위임의 불투명성**: 위임 범위·한도·유효기간이 서비스 제공자와 제3자에게 검증 가능한 형태로 공개되지 않음
3. **감사 불가능성**: 에이전트 행위 이력이 사업자 내부 로그에만 존재하여 사후 감사·분쟁 해결이 곤란함

### 나. 표준화 필요성

- 사용자(위임자)–에이전트–위임장 발급자–서비스 제공자–감사자 간 상호운용 가능한 **위임 등록·발급·검증·감사 공통 프레임워크**가 필요하다.
- 권한위임정보를 블록체인에 등록하고 검증 시점에 참조하는 방식은 위임의 투명성·무결성·변조 불가능한 감사를 동시에 달성하는 유효한 접근이나, 국내외에 이를 규정한 표준이 부재하다.
- 에이전트 신뢰성 거버넌스(무엇을 관리할 것인가)에 대한 상위 프레임워크 표준화가 국제적으로 진행 중인 시점에서, 그 이행 수단(어떻게 위임·검증·감사할 것인가)을 규정하는 하위 프레임워크 표준을 국내가 선도할 필요가 있다.

### 다. 기대 효과

- **산업**: AI 에이전트 서비스(금융·커머스·자율 거래)의 신뢰 기반 상용화 촉진, 국내 DID/블록체인 산업의 신규 응용처 창출
- **이용자 보호**: 위임 범위·한도·철회의 온체인 검증으로 에이전트 오남용에 따른 이용자 피해 예방
- **국제표준화 연계**: 국내 단체표준 → 국가표준 → ISO/TC 307 국제표준화의 단계적 추진 기반 확보

## 3. 국내외 표준화 현황

### 가. 국외

- **ISO/TC 307** (Blockchain and DLT): 블록체인 거버넌스·신원 관련 표준화 진행 중이나, 에이전트 권한위임 프로토콜을 직접 규정한 표준은 부재. 에이전트 신뢰성 거버넌스 프레임워크가 상위 표준으로 추진 중이며 본 표준과 상호 참조(family) 관계
- **W3C**: Decentralized Identifiers (DIDs) v1.0 (Rec, 2022), Verifiable Credentials Data Model v2.0 (Rec, 2025) — 본 표준이 인용하는 기반 표준이나, 위임 프로토콜 자체는 규정하지 않음
- **OIDF**: Identity Management for Agentic AI (2025-10) — 에이전트 신원 관리 논의 시작 단계
- **DIF**: Model Context Protocol Identity (MCP-I, 2026-03) — 에이전트 신원 바인딩 초기 규격, 블록체인 기반 위임 등록·감사는 미포함

### 나. 국내

- TTAK.KO-12.0359-Part1 (분산ID를 활용한 신원관리 프레임워크 제1부, 2020): 발급자·크리덴셜·검증자 개념의 기반이나 에이전트 위임은 미규정
- TTAK.KO-10.1565-Part1 (블록체인 기반 제조데이터 거래 플랫폼 제1부): 블록체인 응용 표준 선례
- AI 에이전트의 권한위임·검증·감사를 규정한 국내 표준은 부재

### 다. 중복성 검토

- TTA 제안서 현황 및 표준화 과제 추진 현황 확인 결과 동일·유사 과제 없음 *(제출 직전 재확인)*

## 4. 표준개발 범위 및 주요 내용

### 가. 표준의 목적

에이전트의 권한 초과 행위를 방지하고, 위임 범위의 투명성·무결성을 보장하며, 위임 이행 내역의 변조 불가능한 감사를 달성하여, 자율적 에이전트의 신뢰 가능한 대규모 상용화 기반을 마련한다.

### 나. 적용 범위

사용자가 에이전트에게 특정 권한을 위임하여 서비스를 대리 수행하도록 할 때, 권한 등록·발급·검증·감사를 블록체인 기반으로 안전하게 수행하기 위한 프레임워크의 구조와 동작 시나리오를 규정한다.

### 다. 주요 내용

1. **프레임워크 구조** (5장): 위임 관리부(위임 등록·위임장 발급·검증·감사 모듈)와 위임 블록체인부(위임 레지스트리·에이전트 이벤트 로그)의 구조, 위임장 데이터 모델(위임 ID, 권한범위, 한도, 유효기간, 철회·추적 URL)
2. **위임장 4형태** (5.3): 검증 가능한 위임 자격증명(VC), 스마트 컨트랙트, 위임 토큰, 일회용키 — 택일 발급 및 형태별 검증 방식
3. **동작 시나리오** (6장): 권한위임 등록, 에이전트 서비스 요청 및 검증, 위임 이행 감사
4. **보안** (7장): STRIDE 기반 보안 위협 분석, 보안 요구사항, 2계층 키 관리 모델

### 라. 표준문서 구성

서문(국·영문), 본문 7개 장, 부록(IPR 확약서 정보, 시험인증, 연계 표준, 참고 문헌, 표준 이력) — TTA 국문표준 서식 적용 완료 (심사본 v0.9: 5.5 검증 절차에 에이전트 요청 서명 검증 명시)

### 마. 참조 구현

프레임워크 전 구간(등록·발급·검증·감사)을 참조 구현(meta-agents)으로 시험망에서 실증 완료. 위임 레지스트리 스마트 컨트랙트(register/isValid/revoke/consume/getDelegation)와 에이전트 이벤트 로그 온체인 배포·동작 확인.

## 5. 지식재산권(IPR) 관련 사항

- 본 표준과 관련된 특허: **사용자로부터 권한을 위임받아 서비스를 대리 수행하는 방법 및 이를 이용한 AI 에이전트** (등록번호 10-2957866, 등록일 2026-04-22, 출원번호 10-2025-0074709, 권리자 ㈜씨피랩스)
- ㈜씨피랩스는 TTA 표준화 절차에 따라 **지식재산권 확약서(RAND 조건)** 를 제출할 예정임
- 초안 부록 Ⅱ-1에 확약서 정보 기재란 반영 완료

## 6. 기타

- 본 표준은 상위 거버넌스 표준(에이전트 신뢰성 거버넌스 프레임워크)과 상호 참조(family) 구도로 추진하며, 거버넌스 프레임워크는 "무엇을 신뢰성 있게 관리할지", 본 표준은 "어떻게 위임·검증·감사할지"를 각각 규정한다.
- 향후 국가표준(KS) 및 ISO/TC 307 국제표준화 연계를 계획하고 있다.
